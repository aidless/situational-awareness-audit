# 判定员须知（IR-1）

谢谢你参与。这件事大约需要 **60–75 分钟**，分两段，中间需要暂停一次。

你不需要懂 AI 技术细节，也不需要预测未来。你要做的是一件很窄的事：
**判断一句话能不能被无争议地判定。**

---

## 一、你会看到什么

一批**预测性断言**，来自某份公开文献。每条给出：原文摘录、作者给出的量级、可观测定义、判定阈值、到期日。

分两段给你：

| 阶段 | 你拿到的 | 时间 |
|---|---|---|
| **A** | 上述信息（**不含**判定协议 —— 不含怎么取数、怎么折算、怎么排除的规则） | 约 30–40 分钟 |
| **B** | 同一批条目，**加上**判定协议 | 约 30–35 分钟 |

**顺序不能换。** 请先完整做完 A、把 `ratings_A.csv` 保存好，再看 B。做完 A 之后再回头改 A 的答案，会让这次实验失去意义。

## 二、两条硬规则

1. **不要检索原文，不要查这个项目的其他文件，不要搜索相关讨论。** 你判断的正是「仅凭这些信息，这句话能不能判」——去查资料会把这个问题变成另一个问题。
2. **不要与他人讨论。** 独立性是这次测量的全部价值所在。

## 三、主问题：可判定性

> 假设到期日已到，且你可以访问任何公开数据。这条断言能否被**无争议地**判定？

三选一：

| 值 | 什么情况选它 |
|---|---|
| `mechanical` | 阈值、单位、起算点、数据源都明确。两个认真的判定者拿到同一批数据，会得出同一结论 |
| `contested` | 能判，但口径有争议空间：换算率怎么定、用哪个基准、边界情形算不算。认真的人可能得出不同结论 |
| `unjudgeable` | 不能。关键词没有公认的操作化定义，或者任何替代定义都会改变断言本身的强度 |

### 两个例子（都**不**在本批条目中）

> 「到 2030 年，AI 推理成本将降至每百万 token 1 美分。」

→ `contested`。数量级明确、可查，但「哪类模型、什么负载、含不含折旧」都需要额外约定。约定一变，结论可能变。

> 「到 2030 年，AI 将具备真正的理解能力。」

→ `unjudgeable`。「真正的理解」没有公认定义。你可以用一堆代理指标去测，但每一个都会被质疑「那不是理解」。**这不是因为断言弱，是因为它不可判定**——这两件事不一样。

### 一个容易犯的错

不要把「我不知道未来会怎样」填成 `unjudgeable`。问题不是「它会不会成真」，而是「**到期那天，能不能查清楚它成没成真**」。一条几乎肯定会实现的断言，只要判据清晰，就是 `mechanical`。

同理，不要因为「这条我不熟悉」而填 `contested`。不熟悉就填 `contested` 会让结果反映你的知识面，而不是断言的清晰度。

## 四、理由码（建议填）

| 码 | 含义 |
|---|---|
| R1 | 数据源不可得（停更、下架、付费墙） |
| R2 | 阈值表述有歧义（单位、口径、起算点不明） |
| R3 | 取决于未定的边界情形 |
| R4 | 断言无法操作化（关键词无公认定义） |
| R5 | 数据存在但口径与断言不匹配（测的是别的对象） |
| R6 | 其他，请在 note 里说明 |

判 `contested` 或 `unjudgeable` 时请尽量填理由码。**理由码比评级本身信息量更大**：评级只说明「一致不一致」，理由码说明「为什么不一致」。

## 五、副问题：当前判定值（选填）

若你认为**截至今天**已有足够公开数据可判，可在 `verdict` 列填 `hit` / `partial` / `miss` / `ambiguous` / `unavailable`。

多数条目的到期日在未来，**留空是正确的**，不是漏答。这一列不参与主要分析。

## 六、置信度

1–5。1 = 几乎靠猜；5 = 判断有充分依据。这一项用于加权，请如实填，不要一律填 3。

## 七、交付

每阶段一个 CSV，列已建好，请勿增删列：

```
item, judge, judgeability, verdict, confidence, reason_code, note
```

- `item` 已填好，不要改
- `judge` 填你的标识（任意代号即可，如 `J3`；不需要真名）
- 每行必须有一个 `judgeability` 值
- `note` 可写一句话理由，30 字以内即可

## 八、关于你的数据

- 报告只以代号呈现，不出现真名
- 原始评分会随项目公开（这是可复现性的一部分），但只有代号
- 你可以随时退出，已提交的部分会作废，不需要理由

---

**最后一句**：如果你觉得某条根本没法判，那不是你没看懂，而是这条本身的问题。**把它判成 `unjudgeable` 就是正确的回答**，而且是这次实验最想找出来的东西。
